# AI-Powered Cybersecurity Threat Detection

## Overview
This project is an AI-powered cybersecurity threat detection system that identifies malicious network traffic using Deep Learning and real-time analytics.

The system detects attacks such as:
- DDoS
- PortScan
- Bot Attacks
- Brute Force
- Web Attacks

Built using:
- TensorFlow / Keras
- Streamlit
- FastAPI / Flask
- Scikit-learn
- Plotly

---

## Features
- Multi-CSV Upload Support
- Real-Time Threat Prediction
- Interactive Threat Analytics Dashboard
- Deep Learning LSTM Model
- CICIDS2017 Dataset Support
- Attack Visualization Charts
- Download Merged Dataset

---
